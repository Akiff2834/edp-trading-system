# Event-Driven Trading System

This project implements an **Event-Driven Trading System using Python**.  
The system simulates essential trading operations such as price updates, buy/sell orders, and stop-loss executions.

---

## **📌 Project Features:**
- **Price Updates** 📈 - Generates random price updates.
- **Trading Operations** 📊 - Traders can place buy/sell orders.
- **Stop-Loss System** ⛔ - Automatically sells assets when the price drops below a set threshold.
- **Trade History** 📜 - Stores executed trades for future reference.
